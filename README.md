# YouTube Site Thing

A custom YouTube-like site that allows users to search and stream YouTube videos without leaving our platform.

## Features
- 🔍 YouTube search functionality
- 🎬 Embedded video playback
- 📱 Responsive design
- 🎨 Custom UI/UX
- ⚡ Fast search and load times

## Tech Stack
- **Frontend**: React.js + TypeScript
- **Backend**: Node.js/Express
- **API**: YouTube Data API v3
- **Database**: (To be determined)
- **Styling**: Tailwind CSS

## Getting Started

### Prerequisites
- Node.js (v16+)
- npm or yarn
- YouTube API Key (https://developers.google.com/youtube/registering_an_application)

### Installation
```bash
# Clone the repository
git clone https://github.com/OwenCosta/YoutubeSiteThing.git

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Start development server
npm run dev
```
